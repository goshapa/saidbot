# SaidBot — продажа Telegram Stars, Premium и донатов в игры

Telegram-бот на **aiogram 3** + веб-админка на **FastAPI** + **Mini App** (веб-каталог внутри Telegram) для продажи:
- ⭐ Telegram Stars
- 💎 Telegram Premium
- 🎮 Донатов (внутриигровой валюты) в играх

## Как это работает

1. Пользователь открывает каталог — либо кнопками прямо в чате бота, либо через **Mini App** (кнопка «🛍 Открыть магазин» / системная menu-кнопка), и указывает получателя (username в Telegram или Player ID в игре).
2. Бот/мини-апп показывает реквизиты карты (UzCard/Humo) и просит прислать скриншот чека после оплаты.
3. Заказ падает админу в чат/группу (кнопки «Подтвердить» / «Отклонить» / «Выполнено») и одновременно виден в веб-админке — не важно, оформлен он через чат или через мини-апп.
4. После подтверждения оплаты админ вручную выполняет заказ (покупает звёзды/премиум/донат нужным способом) и отмечает заказ выполненным — пользователь получает уведомление на каждом шаге.

> ⚠️ Автоматической выдачи звёзд/премиума/доната "из коробки" нет — у Telegram Bot API нет публичного метода для программной покупки и отправки Stars/Premium произвольному пользователю, а у игр нет единого API для донатов. Раздел `bot/services` — то место, где стоит подключать конкретных поставщиков (например, Fragment API для Stars/Premium или API конкретных игровых топ-ап сервисов), когда они появятся.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID (и других админов через запятую)
- `ADMIN_CHAT_ID` — куда слать уведомления о заказах (можно тот же ID)
- `ADMIN_PANEL_USERNAME` / `ADMIN_PANEL_PASSWORD` / `ADMIN_PANEL_SECRET` — доступ к веб-админке

При первом запуске в базу автоматически добавятся демо-категории и товары (звёзды, премиум, несколько игр) и одна тестовая карта — отредактируйте их через админку.

## Запуск бота

```bash
python -m bot.main
```

## Запуск веб-админки

```bash
uvicorn admin.main:app --reload --port 8000
```

Откройте `http://localhost:8000`, войдите под `ADMIN_PANEL_USERNAME` / `ADMIN_PANEL_PASSWORD`.

В админке можно:
- смотреть заказы, чек оплаты, подтверждать/отклонять/закрывать заказ;
- управлять каталогом товаров (звёзды/премиум/донаты);
- управлять картами для приёма оплаты.

## Запуск Mini App (веб-каталог внутри Telegram)

```bash
uvicorn webapp.main:app --reload --port 8001
```

Mini App должен быть доступен по **публичному HTTPS-адресу** — локально его можно открыть только через туннель (ngrok и т.п.), Telegram не откроет `http://localhost`. Проще всего задеплоить его на Railway (см. ниже) и указать выданный домен в переменной `WEBAPP_URL` — тогда бот сам добавит кнопку «🛍 Открыть магазин» и системную menu-кнопку.

Frontend лежит в `webapp/static/` (обычный HTML/CSS/JS, без сборки), backend — в `webapp/main.py` (FastAPI). Авторизация пользователя внутри мини-аппа проверяется по `initData`, подписанной Telegram HMAC-подписью на основе `BOT_TOKEN` (см. `webapp/telegram_auth.py`) — сторонний сайт подделать её не может.

## Деплой на Railway (просто, без терминала)

1. Зайдите на [railway.app](https://railway.app) и войдите через свой GitHub-аккаунт.
2. Нажмите **New Project → Deploy from GitHub repo** и выберите репозиторий `goshapa/saidbot`.
3. Railway сам найдёт `Procfile` и предложит запустить процесс `worker` (это и есть бот). Если спросит тип сервиса — выберите **Worker** (не Web), боту не нужен открытый порт.
4. Откройте вкладку **Variables** этого сервиса и добавьте переменные (значения — как в вашем `.env`):
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `ADMIN_CHAT_ID`
   - `DATABASE_URL` (можно оставить `sqlite+aiosqlite:///./data/saidbot.db`)
   - `CURRENCY`
5. Нажмите **Deploy**. Через минуту бот начнёт отвечать в Telegram.
6. (Опционально) чтобы поднять админ-панель — добавьте в этом же проекте ещё один сервис из того же репозитория, задайте ему **Custom Start Command** `uvicorn admin.main:app --host 0.0.0.0 --port $PORT`, и добавьте туда `ADMIN_PANEL_USERNAME`, `ADMIN_PANEL_PASSWORD`, `ADMIN_PANEL_SECRET`.
7. Чтобы поднять **Mini App**: добавьте ещё один сервис из того же репозитория, задайте ему **Custom Start Command** `uvicorn webapp.main:app --host 0.0.0.0 --port $PORT`, зайдите в **Settings → Networking** этого сервиса и нажмите **Generate Domain** — получите публичный `https://<что-то>.up.railway.app`. Скопируйте этот адрес в переменную `WEBAPP_URL` у **worker**-сервиса (бота) и передеплойте бот — появится кнопка «🛍 Открыть магазин».

> На бесплатном плане Railway база SQLite не сохраняется между переустановками диска — для реального использования подключите Railway PostgreSQL (кнопка **New → Database → PostgreSQL** в том же проекте) и укажите выданный `DATABASE_URL` в переменных (замените префикс на `postgresql+asyncpg://`).

## Продакшн-заметки

- SQLite (`data/saidbot.db`) подходит для старта; при росте нагрузки — перейти на PostgreSQL, поменяв `DATABASE_URL`.
- Бот и админка — два независимых процесса, использующих общую БД; для прод-окружения удобно поднять их через systemd/docker-compose.
- Проверьте, что модель работы (перепродажа Stars/Premium/донатов за деньги вручную) не противоречит правилам Telegram и локальному законодательству, и подключите настоящий процессинг/эскроу, если объёмы вырастут.
